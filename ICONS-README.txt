📱 PWA Icon Instructions

You need to create app icons in these sizes:
- icon-192.png (192x192 pixels)
- icon-512.png (512x512 pixels)

🎨 Design Tips:
- Use your app logo or a book/dictionary icon
- Simple, bold designs work best
- Use your brand colors (#4361ee blue)
- Make sure it looks good on both light and dark backgrounds

🔧 Easy Ways to Create Icons:

1. **Online Tools (Easiest):**
   - https://www.favicon-generator.org/
   - https://realfavicongenerator.net/
   - Upload any image and it generates all sizes

2. **Canva (Free):**
   - Create 512x512 design
   - Export as PNG
   - Resize to 192x192 for smaller version

3. **Use an Emoji (Quick Test):**
   - Take a screenshot of 📚 or 📖 emoji
   - Resize to 192x192 and 512x512

For now, you can use ANY image - just rename it to:
- icon-192.png
- icon-512.png

Place them in the root folder next to app.html
