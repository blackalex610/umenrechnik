🧪 TESTING ON DESKTOP (Chrome/Edge):

1. Make sure your server is running:
   cd "c:\Users\pc\Desktop\erazum bilet"
   python -m http.server 8000

2. Open Chrome/Edge and go to:
   http://localhost:8000

3. Open DevTools (F12) → Application tab
   - Check "Manifest" - should show your app info
   - Check "Service Workers" - should be registered

4. Look for "Install" icon in address bar (⊕ or ⬇)
   - Click it to install as desktop app
   - App opens in its own window!

📱 TESTING ON MOBILE:

ANDROID (Chrome):
1. Open Chrome on your phone
2. Visit your deployed website (NOT localhost)
3. Tap the ⋮ menu → "Install app" or "Add to Home screen"
4. App appears on home screen like native app!

iOS (Safari):
1. Open Safari on iPhone
2. Visit your website
3. Tap Share button → "Add to Home Screen"
4. App appears on home screen!

NOTE: For mobile testing, you need to:
- Deploy to a real domain (GitHub Pages, Netlify, Vercel)
- OR use ngrok to tunnel localhost to internet
- Mobile can't access localhost directly

🔧 CUSTOMIZATION:

Edit manifest.json to change:
- name: App name in full
- short_name: Name under icon (12 chars max)
- theme_color: Address bar color
- background_color: Splash screen color
- description: App description

Edit service-worker.js to:
- Add more files to cache
- Change cache strategy
- Update cache version (increment v1 → v2)

═══════════════════════════════════════════════════════════════

🐛 TROUBLESHOOTING:

Problem: Service worker not registering
Solution: Check browser console for errors, must use HTTP or HTTPS (not file://)

Problem: Install button doesn't appear
Solution: Need icons + HTTPS (or localhost) + manifest linked

Problem: Changes not showing
Solution: 
- Update CACHE_NAME in service-worker.js (v1 → v2)
- Hard refresh (Ctrl+Shift+R)
- Unregister service worker in DevTools

Problem: Can't test on phone
Solution: Deploy to real domain or use ngrok:
  1. npm install -g ngrok
  2. ngrok http 8000
  3. Use the https URL on phone
